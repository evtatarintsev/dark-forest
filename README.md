# Тёмный лес (Dark Forest)

Браузерная игра-приключение / экшен на выживание от первого лица. Самолёт игрока разбивается в тёмном лесу; выбравшись, он находит раненого охотника **Грома** и должен заслужить его доверие, выполняя задания, — пока не наступила ночь и не пришли волки (а с 7-го дня — медведь).

Игра не требует установки: это самодостаточные HTML-файлы, которые открываются прямо в браузере.

## Файлы

- **[`dark_forest_3d.html`](dark_forest_3d.html)** — основная, актуальная версия игры. 3D от первого лица на [Three.js](https://threejs.org/) (r128, WebGL), без сборки и серверных зависимостей — только CDN-подключение Three.js.
- **[`dark_forest.html`](dark_forest.html)** — более ранний 2D-прототип на `<canvas>` (top-down, без Three.js). Оставлен для истории/сравнения.

## Как запустить

Просто откройте `dark_forest_3d.html` в браузере (Chrome/Firefox/Edge, десктоп). Для работы нужен доступ в интернет — Three.js подгружается с CDN.

```bash
open dark_forest_3d.html
```

## Сюжет и геймплей

Охотник Гром лежит у потухшего костра с вывёрнутой ногой — сам передвигаться не может, все задания выполняет игрок. Три последовательных квеста (каждый — с диалогом и выбором «Принять / Отказать»):

1. **Хворост для костра** — собрать 3 вязанки хвороста и разжечь костёр.
2. **Отгони волков** — победить 3 волков у лагеря; после этого в лесу становится виден скрытый выход.
3. **Найди тропу** — дойти до выхода и вернуться к охотнику.

Другие механики:
- Цикл дня и ночи (1 день = 90 сек.), ночная осада дополнительными волками, медведь начиная с 7-го дня.
- Река без моста — переходится вброд, замедляет и грозит утоплением при долгом нахождении в воде.
- Инвентарь, крафт на верстаке (нож, топор, факелы) из палок и трофеев (клыки волков, коготь медведя).
- Сбор ресурсов: лечебные травы (возрождаются), палки, хворост.
- Гид-стрелка, указывающая направление к текущей цели.

Полное техническое задание с деталями по каждой системе — в истории обсуждения проекта (карта, освещение, боёвка, условия победы/поражения и т.д.).
